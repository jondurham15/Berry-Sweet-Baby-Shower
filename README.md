## Before sharing
1. Open `index.html` in a browser to preview the website.
2. The RSVP button is already connected to the Google Form provided by the hosts. Test that the form accepts responses before sharing.
3. The five uploaded photos are already included in the `photos/` folder. Keep this folder beside `index.html` when publishing.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new public repository.
2. Upload `index.html` and the complete `photos/` folder.
3. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub will provide a public website link after deployment.

The page is plain HTML, CSS, and JavaScript, so it does not require a paid website builder or server.
